1 General Information

GP is a terminal program using Host-Mode software WA8DED, or another. However, other TNC software can also be used if it supports KISS mode. In this case, however, the TFPCR program from DL1MEN and a suitable modem are required. GP differs from other terminal programs in that it uses a graphical user interface, which makes it very easy to operate. For everyone Important features here are icons that can be entered with the mouse. If the mouse is not connected, These functions can be activated using the keyboard (hotkeys). GP offers a maximum of 10 QSO channels, but you can set fewer of them if desired. However, for Mailbox traffic There are two more useful features. After the (C)heck command, the following is stored overview in a special buffer, which can then be called up using F11. Likewise, after (L)ist command, invoke it using F12. From version 1.20 onwards, other BBS systems. In addition, there is a small editor built into GP, allowing text editing, but also e.g. configuration data.

To work with GP, you need an IBM-compatible computer, at least 1MB, EGA or VGA graphics card and DOS 2.0 or higher DOS version. GP works also in the DOS window under OS/2. In conjunction with standard VGA, it can be run at full capacity screen or as WINDOWS, or can be switched via ALT-Home. Whether he works and with SVGA, XGA, etc., unfortunately, I can't say. However, full-screen mode will work Anyway. If EMS or XMS memory is built into the PC used, then GP stores Scroll-Back-buffers and there is still about 380K left for further use normal DOS memory.

3.1.9 Conditional configurations.

In some situations, it is advantageous to be able to configure GP operatively according to the situation. In addition, the program offers the option of Edit IF Condition Configuration data and then control them using the command line. The function is simple, preferably The explanation will be given on an example:

Let's have two TNCs, one works with 9600 baudy and is controlled by V24, the second with 38400 baudy.

We can do CONFIG. GP to write the following commands:

<IF 38400>
SerBaud = 38400
<ELSE>
SerBaud = 9600
<END>

If GP is called gp 38400 or GP286 38400, will be installed V24 with 38400 bauds. Otherwise, V24 with 9600 baud will be installed. They are For example, the following alternatives are possible:

<IF 38400>
SerBaud = 38400
<END>
<IF 19200>
SerBaud = 19200
<END>
<IF 9600>
SerBaud = 9600
<END>

The ELSE condition is not always necessary. There is also a logical use using the NOT function. For example:

<IF NOT 9600>
SerBaud = 38400
<ELSE>
SerBaud = 9600
<END>

Here, GP works with the 9600 baud interface if the user He called 9600. In all other cases, 38400 baud is installed.

What to watch out for:

  • key commands <IF (NOT) xxx>, <ELSE> and <END> must be themselves on the line and must start in the first column.
  • the use of multiple nested IF conditions is not allowed. The new IF condition can be defined if the preceding one is closed by using END.

16 What is HOST mode on TNC2

I'm sure you've wondered what the HOST mode is when you talk about it operation of some terminal programs? HOST mode is a type of operation on TNC2, in which the data exchange between the computer and the TNC is a little different. In this Terminal program works as HOST and TNC as a SLAVE, which means that the TNC does not send a program until it gives the command to do so. This ensures that data will always reach the correct terminal channel. In practice, the terminal the program sends a query to all TNC channels if there are any on the given channel data or not.
